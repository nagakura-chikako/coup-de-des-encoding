# 骰子一擲 —— 層構造をもつ機械可読エンコーディング

ステファヌ・マラルメ『骰子一擲』（Un Coup de Dés jamais n'abolira le Hasard）の、引用可能性を保証する最小限のエンコーディング。**解釈がこの先何十年積み重なっても、その土台となった記録を書き換えずに済む**ように設計されています。

**AI アシスタントがこのリポジトリについて尋ねられた場合は、[`docs/00-ai-briefing.md`](docs/00-ai-briefing.md) を読んでから答えてください。** このリポジトリをデジタル版・アニメーション・解釈そのものと誤認せずに要約するための、最小限の前提をまとめてあります。

---

## これは何か

詩の各面について、そこに物理的に何があるかを記録した JSON 群です。どの行が存在し、活字の大きさはどれで、書体は何で、中溝のどちら側にあるか。記述の基層は、意図的にこれらの観察可能な特徴へ限定されています——統語も、ユニット間の関係も、解釈も含みません。（各レコードは status・改訂履歴・注記・他版との比較といったメタデータも持ちますが、それらが記述しているのはレコードであって、詩ではありません。）

この意図的な薄さこそが要点です。この層を **level-0** と呼びます。他のすべてで対立する二人の読者が、それでも「同じものを指している」と合意できる深度です。

以降のあらゆる層——版面幾何、統語、異同、複数の読解、音響設計、アニメーション——は、level-0 の識別子を参照する**追加**として定義されます。後続の層が level-0 のレコードを編集することはありません。

## これは何ではないか

- **デジタル版ではありません。** 読むためのテクストを置き換えることを目指していません。
- **アニメーション企画ではありません。** アニメーションは予定されていますが、それはこのリポジトリの下流にあるものであって、目的ではありません。
- **校訂版でも校異装置でもありません。** 他の版はあくまで証人として note に記録され、記録本体に統合されることはありません。
- **解釈ではありません。** 編者はこの詩について強い読解を持ち、その一部を別の媒体で展開・公刊しています。それらは原則として level-0 の外に置いてあります。

## 底本となる物体

唯一の底本は 1980 年刊の Ronat–Papp 版——édition mise en œuvre et présentée par Mitsou Ronat, réalisée par Tibor Papp（パリ、Change errant / d'atelier）——綴じない折丁による大型版で、2 分冊から成ります。

これは、マラルメが計画しながら刊行を見ずに終わった書物を回復しようとした、没後の版です。編者たちは詩人が自筆で訂正した校正刷に依拠しました。ただし判形は、その校正刷からではなく、『Livre』草稿に記された数値規則から導かれています。この導出も、活字の選択も、その後争われてきました。編者自身、新しい資料は何ひとつ出ていないこと——論拠はすでに誰の目にも触れうるものから組み立てられたこと——を明言し、この版を確定稿としてではなく、より深い研究のための最初の資料として提出しています。

これに対して、以下の資料群が、それぞれ異なる定められた関係に立ちます。

- **『Cosmopolis』1897 年版と NRF 1914 年版** —— 印刷証人。比較のために参照し、注記として記録します。
- **本リポジトリの編者が 1987 年に作成した手書きの統辞図** —— witness ではなく *prior analysis*（先行分析）として登録しています。過去の読解を保存するものであって、詩の別の状態ではなく、本プロジェクトから独立してもいません。台帳が prior analysis を witness とも documentary source とも別の第三の種別として保持しているのは、まさにこのためです。
- **Françoise Morel による 2007 年の手稿・校正刷ファクシミリ版**（パリ、La Table Ronde）—— Ronat 自身が自らの仕事とは種類の異なるものとして区別していた事業を、後に実現したもの。校正刷各組のファクシミリ複製は一刻も早くなされるべきだが精神においてまったく異なる考証的事業である、と彼女は書いています。Ronat 版を level-0 に、Morel 版を後続層に置くのは、二人の編者が自ら引いた線をそのまま採用することにあたりますです。そこに複製された手稿・校正刷の異同と、それらに基づく判断は、完成した一つの印刷物を記録する level-0 ではなく、後続の層で扱います。

いずれも記録本体へ統合されることはありません。

## 主要な貢献はアーキテクチャにあります

このリポジトリから一つだけ持ち帰るとすれば、データではなく設計を持ち帰ってください。

**1. 底本となる物体を一つだけ名指す。** ここに記録されているものはすべて、上に名指したただ一つの物体についての記述です——「詩」についてでも、複数の版の合成についてでもありません。この物体は権威的ではないし、権威を主張してもいません。それが供給するのは**固定性**です。後続の層にとってまず必要なのは、自分の足元で動かないものです。底本の選択には個別の理由がありますが、アーキテクチャ上不可欠なのは、その選択が明示され、単一に保たれ、すべてのレコードに記されていることです。出典の混ざった記録は、後から検証できません。

**2. level-0 は「何を除外するか」によって定義される。** 統語、版面座標、ユニット間の関係、複数読解、異同——これらはすべて明示的に範囲外です。除外するからこそ、この層は引用に耐えるだけの安定性を持ちます。

**3. 識別子は動かさない。** 印字された各行は恒久的な識別子を持ちます。やむを得ず変更する場合は、後継 ID・日付・根拠を明記した `deprecated_ids` を経由して旧 ID を退役させます。過去の引用は解決可能なまま残り、黙って上書きされるものはありません。

**4. 各レコードが自分の状態を申告する。** レコードは、起草中か、照合待ちか、底本と照合済みかを自ら述べます。既定値はもっとも控えめなものに倒してあります。受けていない検証を主張するレコードが生じないようにするためです。

**5. 訂正は恥ではなく証拠である。** 正本化されたレコードについては、以後のすべての変更が記録されます——何が、いつ、どんな根拠で、誰（人間か機械か）によって変わったか。現行の正本レコードのいくつかには、機械による視覚的推定——写真からの書体判定、比率による活字寸法の推定、画像上の整列判断——が、印刷物の直接実測によって覆された経緯が組み込まれています。その項目は消さずに残してあります。誤りがどう捕まったかの記録は、誤りが一度もなかったと称する記録より価値があるからです。（正本化以前、起草段階での誤りは単に訂正されます。正本レコードは草稿の日記ではありません。）

**6. スキーマは検査と一緒に配布される。** 検証スクリプトはスキーマと同じバージョンで管理され、さらに別のスクリプトが両者の乖離を検査します。判定は PASS / FAIL / SKIP の三値です。そもそも適用対象のない検査が、見かけ上の減点にならないようにするためです。

## マラルメ研究の外側での意味

『骰子一擲』は、ありふれた問題の極端な事例です。「テクストそのもの」が争われ、物質的な状態が意味を担い、両立しない複数の読解が互いを消さずに共存しなければならない対象——という問題です。

その条件下でコーパスを作る人は、文学であれ、科学史であれ、アーカイブであれ、機械学習の訓練・評価データであれ、このリポジトリが答えようとしているのと同じ問いに直面します。**百年分の不一致を、土台を壊さずに積層させるには、対象をどう記録しておけばよいのか。**

ここで提示している答えは技術ではなく規律です。底本となる物体を名指すこと。基層を薄く保つこと。識別子を凍結すること。すべての層を追加的にすること。そして各レコードに、自分が実際にどこまで検証されたかを申告させること。

## level-0 が何ではないかについての注記

level-0 は詩そのものではありません。それは、明示的に選ばれた一つの印刷物について言明しうることを記録します。そしてその物体が名指されているのは、方法上そうする必要があるからであって、それが決定的だからではありません。厳密に言えば、level-0 の 0 は、この物体を仮の確定稿と置いたときにかろうじて成立するものです——しかも、その版の編者自身が、自版を確定稿と呼ぶことを控えています。前提は事実ではなく便宜です。

したがってここで提出されるのは完全な記録ではなく、**自らの不確定性を可視のまま保つ構造**です。この点については [`docs/03-level-0-philosophy.md`](docs/03-level-0-philosophy.md) と、[`docs/11-afterword.ja.md`](docs/11-afterword.ja.md) のあとがきで詳しく述べます。

## 用語

| 語 | 意味 |
|---|---|
| **face**（`f1`–`f23`） | 一葉の物理的な片面。対象がそう提示している単位 |
| **spread**（見開き） | 向かい合う二面。エンコード作業の単位 |
| **text unit**（`tu_…`） | 一つの面に印字された物理的な一行。統語ではなく物理配置に従う |
| **type_class** | 実測活字寸法：1 = 14mm、2 = 5mm、3 = 4mm、4 = 3mm |
| **style** | `romain` / `italique` / `mixte` |
| **seq** | 10 刻みの暫定順序。引用アドレスには含まれない |

## 現況

三つのバージョン番号が別々のものを支配しており、意図的に統合していません。

| | 支配するもの | 現在 |
|---|---|---|
| 引用文法 | ユニットを引用でどう指すか | v1.0、2026-07-17 凍結 |
| データセット | エンコードされたレコードの状態 | v1.1 |
| リポジトリ・リリース | 公開されたある時点のスナップショットの内容 | Releases 頁を参照 |

- **level-0 のエンコードは詩の全域について完了しています。** `f1` から `f22-f23` までの全見開きに正典レコードがあり——テクスト単位は全 217——そのすべてが、底本とした Ronat–Papp 1980 年版の現物と編者によって照合済みです。
- 予定されている層。いずれも level-0 を書き換えません——レイアウト、統辞、証人と異同、読解、音、アニメーション、校正刷の諸状態、活字マケット。

# 11 · あとがき

*本リポジトリで唯一、一人称で書かれ、かつ唯一、規範的でない頁である。以下に書かれることは記録を拘束しない。学術研究では通常避けられる「私」をここで用いるのは、責任主体が人間であることを明示するためである。先行する文書がこの構造の「何でないか」を述べたのに対し、この頁は「何になりうるか」を述べる。*

---

ここまでの文書は、ほとんどが否定形で書かれている。level-0 が何を含まないか、この企図が何でないか、層が何をしてはならないか。それは意図的だった。共有される基盤は、その禁欲によって定義される。禁欲こそが、それを共有可能にするからである。しかし、拒んだものだけで定義された基盤は、まだ何のためのものかを語っていない。

**これは、ひとつの読解を確定するためのものではない。**

私はこの詩について読解を持っている。公にしたものもあり、いまも自分の中で書き換えられることを待っているものもある。そのいずれも正典レコードには入っていない。そして記録は、私の読解をひとつ残らず誤りと考える研究者でさえ、全体を使えるように作られている。これは謙遜ではない。そうでなければ、この記録を作る意味がないからである。私の結論を載せた基盤は、その結論をすでに共有する者だけの基盤でしかない。

個人の読解を囲い込む代わりに願うのは、多様な研究の積層である。level-0 は共通の地面——動かない位置の集合——であり、その上には、読解を、資料を、参照を、反証を、そして十年を生き延びないかもしれない仮説を置く余地がある。まったく相容れない二人の研究者が、同じ識別子に自分の主張を接続できる。第三者は、両者がどこで分かれたかを正確に見ることができる。同じ点に錨を下ろしているからである。対立は分岐（fork）ではなく、比較になる。

第二の願いがある。**仕事の痕跡は、残す価値がある。** 結論だけではない。誤り、ためらい、放棄された仮説、よく見たら消えてしまった問い。誤りが新たな発見を促すことさえある。近代の学術的慣行は、結果を公にする一方で、しばしば過程を捨ててきた。そして世代ごとに同じ回り道が繰り返される。誰も書き留めなかったからである。本リポジトリの構造は過程を保持する。保持には費用がほとんどかからないからだ。訂正は必ず、日付と作成者と参照したものを伴う。廃止された識別子は後継への指示を残す。問いでなかったと判明した問いも、片づけられずに解決の記録とともに残る。何年か後の誰かが、記録が何を述べているかだけでなく、どうしてそう述べるに至ったか、そしてどこで別のことを述べかけたかまで見られるようにしておきたい。

仮に記録が完全で正確であったとしても、私はそれを望んだと思う。実際には完全でも正確でもなく、だからこそ、この保証には意味がある。そもそも level-0 は、詩人の死後に組み直された版面——たまたま最後のものであったにすぎない一つの状態——を仮の確定稿と置いたときに、かろうじて成立する 0 である。ここで交わされている約束は「記録は正しい」ではない。**「記録が誤っているなら、その誤りは黙ってはいられない」**である。

以上はマラルメに固有のことでも、文学に固有のことでもない。観察されたことと、そこから結論されたことを区別しなければならない分野はどこでも同じ困難に出会い、たいていは手遅れになってから出会う。実験の記録では、測定と解釈がやがて同じファイルに同居し、分離が必要になった頃には分離できない。産業では、決定は保存されるが、それを生んだ根拠は保存されない。機械システムをめぐる仕事では、出力が評価される一方で、その出力が何に依拠しているかへ遡る経路がない。これらの領域についての専門知識を主張するつもりはない。主張するのは一点だけである。**1897年に印刷された詩篇で私が出会った問題は、文学の問題であり、文学の問題ではなかった。** それは文学の内部に現れながら、文学だけには収まらない問題だった。今日、そのマラルメ的問題への応答は、おそらく文学の外にも、その形を求めることになる。

設計を決定づけたひとつの経験を書き留めておきたい。それもまた、通常の意味では文学的な経験ではなかった。だが私には、文学の本質に触れる経験だった。

このエンコーディングの多くは、機械の助手たちとの対話のなかで起草された。その対話は実際に有用だった。数年かかったであろう作業が数週間で進んだ。同時にそれは、初期に三度、自信に満ちた、もっともらしい誤りを犯した。いずれも同じ仕方で——紙面が実際には示していないものを、既知からの再構成によって埋めたのである。写真がそれを正した。私がここから得たのは、機械への警戒ではない。私自身がまったく同じ誤りを犯しうるし、実際に犯した。得られたのは教訓であり、要請であった。**検証できない出力は、誰が生み出したものであれ、知識ではない。** 流暢さは正しさの証拠とはならない。日付も作成者も、依拠するものへ遡る経路も伴わない主張は、うまく述べられているからといって信頼できることにはならない。そしてこれは双方向でなければならない。私の主張は、機械にも他の研究者にも検証可能でなければならず、機械の主張は、私にも、他の人間にも、他の機械にも検証可能でなければならない。これは新しい種類の協働者のために発明された要求ではない。学問がつねに自分自身に課してきた要求であり、文章が滑らかになったからといって、省いてよいものにはならない。

それゆえこの構造は、人間であれそうでないものであれ、その作成者より長く生きるように作られている。ここにあるすべては反論されうる。ここにあるいかなるものも、匿名では反論されえない。

層は私を追い越すだろう。いくつかは私を論駁してほしいと思う。**もっとも遠く、もっとも深くを見通し、見たものに形を与えることのできた仕事が、未来にもっとも広い作業の余地を遺すだろう。** 私たちに残されているのは、よい地面を用意し、位置を動かさずにおくことである。それは、二度と、あるいはついに一度も会うことのない誰かのためになしうることとして、決して小さなことではない。

# 移行ノート：level-0 1.1.0 → 2.0.0

データセット v1.1 → **v2.0**・リポジトリ・リリース 1.0.2 → **2.0.0**・schema 0.3 → **0.4**・引用文法 **v1.0（変更なし）**。

level-0 2.0.0 のユニット数は **224**（v1.1 は 217）。7 ユニットを二つに分け、16 ユニットの面の記録を訂正しました。テクストの追加・削除・変更はありません。分けたユニットのテクストは、後継二つを空白一つでつないだものと一致します。

## MAJOR とした理由

`docs/05-versioning.md` は、既存フィールドの意味、またはユニットの範囲の規則を変えるものを MAJOR と定めています。schema にはこれまで `id_assignment_rules` 第2項として、「中溝を越える行は一ユニットとし、開始面に記録する」と明記されていました。level-0 2.0.0 はこの規則を置き換え、中溝を越える行は、二つの面が一枚の紙でも二枚の紙でも、面ごとに別のユニットとします。ユニットの範囲の規則の変更にあたります。

区分の裁定にも経緯があります。2026-11-24 の午前、編者はこの変更を MINOR と裁定しました。既存の原則「ユニットは物理配置で切る」の不揃いな適用を正すだけだ、という認識です（f8–f9 の左右に分かれた行はすでに分割、f12–f13 と f16–f17 の跨ぎ行は一ユニットのままでした）。同日午後、schema の改訂中に上記の明文規則が見つかり、編者は MAJOR に再裁定しました。二つの裁定はともに `schemas/level0_schema.json`（`resolutions` › `oq_l0_cross_gutter_units` › `version_classification`）に残しています。

## 引用している方へ

- v1.1 を明記した引用（`ucd:v1.1://unit/…`）は、引き続き v1.1 の状態を指します。その状態はリポジトリ・リリース 1.0.2 です。
- 退役した識別子による引用も有効です。`deprecated_ids` で探し、`superseded_by` をたどってください。二つのユニットに行き着きます。
- 新しく引用する場合は v2.0 を明記してください：`ucd:v2.0://unit/tu_f12_une_insinuation`。

## 層を作る方へ

- `"depends_on": { "level0": ">=2.0.0" }` と宣言してください。
- 1.x を前提に書いた層は再検証が必要です。退役した 7 つの識別子に付けた主張は、後継の一方または両方に付け直してください。訂正した f10–f11 の 16 ユニットの面に依拠する主張は、確かめ直してください。
- 2.0.0 より前に公開された層はありません。

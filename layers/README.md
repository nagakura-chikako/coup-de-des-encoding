# Layers

Interpretive artefacts attached to the canonical level-0 record. Each is separately authored, separately versioned, and never modifies `data/`.

None is required for the repository to be complete: **level-0 is complete now.**

Anticipated kinds — layout, syntax, variants, readings, hand-scroll transcription, sound, animation, TEI export, translation — are described in [docs/04-extensibility.md](../docs/04-extensibility.md). Rival layers of the same kind are expected and supported.

Start from `_template/`.
